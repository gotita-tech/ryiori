# Carta visual de Ryori

La carta local se alimenta de un snapshot del menú público de Ryori en Fudo (`https://menu.fu.do/ryori`) y contiene 328 productos con nombre, descripción, categoría y precio capturados el 7 de octubre de 2026.

Se agregaron 49 fotografías referenciales generadas con ChatGPT Image Generation a partir de los ingredientes publicados para rolls, tablas, ceviches, ensaladas, burgers y Hot Sushi Burger. Cada tarjeta marca estas imágenes como **Foto referencial · IA**. No representan una promesa de presentación exacta: la preparación real puede variar.

La página de carta permite buscar por nombre o ingrediente, filtrar por tipo de producto y abrir el enlace de Fudo para realizar el pedido. Fudo sigue siendo la fuente operativa de precios, disponibilidad y checkout.
